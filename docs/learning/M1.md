# M1: Loop, adapters, FakeModel

## What we built and why
- `agent/loop.py` (209 lines; line-by-line in `LOOP_WALKTHROUGH.md`), `agent/models.py` (adapters + pricing), `agent/context.py`, `agent/trajectory.py`, `agent/prompts.py`.
- **Adapter protocol** (`ModelAdapter.complete`) so the loop never imports a provider SDK. Alternatives: LiteLLM (banned by spec, and hides exactly what we want to show) or Anthropic's Tool Runner (owns the loop for you).
- **FakeModel** replays a script (or a callable over `messages`). It makes the loop testable without a network and gives a free demo (`make demo`).
- **UnsafeLocalEnv** (`sandbox/local_env.py`) let the loop run before the sandbox existed. It refuses to start without `unsafe_local=True` *and* the path being `toy_repo/`.

## Key concepts
- **Provider-neutral history with a `raw` escape hatch** (`models.py` top docstring). Haiku 5.5 binds thinking blocks to the exact prefix, so `AnthropicAdapter.to_wire` replays `raw` unchanged.
- **Haiku 5.5 request surface** (`AnthropicAdapter.request`): adaptive thinking, `output_config.effort`, no sampling params, no prefill, two cache breakpoints (system+tools; automatic end-of-history).
- **Read content by type** (`AnthropicAdapter.parse`): responses may start with thinking blocks.
- **Retryable vs fatal** (`AnthropicAdapter.complete`, `call_with_retries`).
- **Context**: exact anchor from `usage` + `chars/3.5` for new messages (`ContextTracker.estimate`). Compaction returns a *new* list (`compact`).
- **Trajectory** = one JSON line per step, with secrets redacted (`trajectory.redact`).

## Interview questions
1. **Why keep history append-only?** Two reasons: prompt caching is a prefix match, so editing turn 3 re-bills every later token; and current Claude models reject (or silently drop) thinking blocks whose preceding history changed. Compaction respects this by starting a fresh list instead of rewriting the old one.
2. **How do you avoid a retry storm when the API is overloaded?** Exponential backoff with jitter (randomising each delay by ±50% spreads clients out), honour `retry-after`, cap attempts, and make the final failure a clean, recorded stop (`error`) rather than a crash.
3. **How do you test an agent loop without calling a model?** Inject the model: a scripted fake that returns tool calls lets you assert stop reasons, budgets, loop detection, compaction and append-only behaviour deterministically (`tests/unit/test_loop.py`). Inject `sleep` and the clock the same way.

## Break-it exercise
In `loop.py`, change `messages.append({"role": "tool", ...})` so it appends only `results[:1]` (drop all but the first tool result).
**Expected:** `test_parallel_calls_all_get_results` still passes (it reads the trajectory), but with the real API every parallel call would now fail with a 400 ("tool_use ids were found without tool_result blocks"). **Diagnose:** compare the `tool_calls` and `observations` counts in a trajectory step. Lesson: write a test against the *wire format* (`AnthropicAdapter.to_wire`) when you depend on a protocol invariant. Try adding one.
